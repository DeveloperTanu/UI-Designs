# Writive AI

A complete UI/UX case study for an AI-powered writing platform built in Figma.

Writive AI is a concept SaaS product that combines three AI-powered tools into a single ecosystem:

- AI Mail
- AI Notes
- AI Story Writer

The goal of this project was to design a clean, modern, and accessible user experience across multiple product touchpoints, including onboarding, pricing, subscriptions, and payments.

---

## Project Overview

This project explores the end-to-end user journey of a fictional AI writing platform.

Users can:

- Generate professional emails
- Summarize notes and documents
- Create stories and long-form content
- Purchase individual tools
- Upgrade to bundled plans
- Manage subscriptions securely
